# Publisher Copy 使用文档

## 适合谁

这个插件适合经常在 Obsidian 中写公众号文章的人。

如果你遇到过这些问题，它就是为你准备的：

- Obsidian 里图片正常，复制到公众号后台图片没了。
- 粘贴到 Doocs 或其他编辑器后，左边出现一堆 HTML 源码。
- 想从 Obsidian 直接复制到微信公众号后台，不想中间再折腾一次排版。
- 同一篇文章有时要发公众号，有时又要保留 Markdown 格式。

## 两种复制模式

### 公众号格式

快捷键：

```text
Cmd + Shift + C
```

这个模式会复制富文本，适合直接粘贴到微信公众号后台。

它会处理：

- 标题样式
- 小标题样式
- 正文两端对齐
- 引用块
- 代码块
- 图片
- 列表
- 分割线

### Markdown 格式

快捷键：

```text
Cmd + Shift + M
```

这个模式适合粘贴到 Markdown 编辑器。

## 主题设置

进入：

```text
Obsidian 设置 -> 第三方插件 -> Publisher Copy
```

可以调整：

- 公众号主题
- 自定义主色
- 自定义背景色
- 小标题前缀
- 标题下划分隔线
- 主标题对齐
- 正文对齐
- 段落首行缩进
- 主标题卡片

## 推荐搭配

教程类文章：

- 主题：Craft 灵感
- 主标题对齐：居中
- 正文对齐：两端对齐
- 段落首行缩进：关闭
- 主标题卡片：开启

个人表达类文章：

- 主题：熊掌记灵感
- 主标题对齐：居中
- 正文对齐：两端对齐
- 段落首行缩进：关闭
- 主标题卡片：开启

严肃干货类文章：

- 主题：墨色极简
- 主标题对齐：左对齐或居中
- 正文对齐：两端对齐
- 主标题卡片：关闭或开启都可以

## 常见问题

### 图片为什么要特殊处理？

Obsidian 中的图片通常是本地路径，例如：

```markdown
![图片](attachments/demo.png)
```

微信公众号后台无法读取你电脑里的这个本地路径。  
插件会把图片转换成剪贴板可以携带的图片数据，再一起粘贴过去。

### 为什么不继续使用 Doocs？

Doocs 很适合手动排版，但如果从 Obsidian 复制富文本过去，容易出现 HTML 和 Markdown 混在一起的问题。

这个插件的目标是：

```text
Obsidian -> 微信公众号后台
```

减少中间环节。
