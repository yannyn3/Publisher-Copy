# 我做了一个 Obsidian 一键复制公众号排版的小插件

之前我一直有个很烦的问题：

文章在 Obsidian 里写得好好的，图片也正常，结构也正常。

但一复制到公众号编辑器里，要么图片没了，要么格式乱了，要么还要再去 Doocs 里倒腾一遍。

如果只是偶尔发一篇文章，还能忍。

但如果你经常写公众号，这件事就会变成一种很小但持续消耗人的麻烦。

所以我做了一个小插件：`Publisher Copy`。

它的目标很简单：

> 在 Obsidian 里写完，按一下快捷键，直接粘贴到微信公众号后台。

## 它解决了什么

它主要解决三个问题：

1. 本地图片复制到公众号后台不显示
2. Markdown 和 HTML 混在一起导致排版乱
3. 每次都要重新调标题、正文、引用、代码块样式

现在我在 Obsidian 里写完文章后，只需要按：

```text
Cmd + Shift + C
```

就能复制成公众号格式。

如果我要复制 Markdown 版本，就按：

```text
Cmd + Shift + M
```

## 我最喜欢的地方

它不是只解决“能复制”的问题。

我后面又加了主题系统。

现在可以选择：

- 雅致金
- 墨色极简
- 温暖手帐
- 熊掌记灵感
- Craft 灵感

我比较喜欢 `Craft 灵感`，干净、简约，但又不是那种毫无设计感的纯文本。

如果写偏个人表达的文章，我会用 `熊掌记灵感`，有一点纸感和写作氛围。

## 为什么这件事对我重要

因为工具的意义，不是多一个按钮。

而是让一个原本需要反复打断的动作，变成顺手完成。

写文章最怕什么？

不是排版难。

而是刚写完一篇，状态还在，结果被复制、传图、调格式这些琐事消耗掉。

所以我现在越来越喜欢把这些固定动作做成工作流。

少折腾一点，文章就能多发一点。

这可能才是工具真正有用的地方。
