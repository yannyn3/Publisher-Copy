# 日周月报写作助手

一个面向中文职场场景的 Agent Skill，用于把零散工作记录整理成 **日报、周报、月报、阶段总结、工作复盘和述职材料**。

核心目标不是“把事情全部写出来”，而是帮助 Agent 自动完成：

- 合并同类事项，避免流水账；
- 优先突出结果、数据、进度和业务价值；
- 把技术/运营表达翻译成老板容易理解的语言；
- 区分可控与不可控因素；
- 自动提炼问题、优化方向和下一阶段计划；
- 在信息不足时保守表达，不编造数据。

## 技能中文名称

**日周月报写作助手**

内部 Skill ID：`work-report-cn`

> Agent Skills 标准要求 `name` 使用英文小写字母、数字和连字符，因此内部 ID 不能直接写中文。技能正文、说明、触发描述均已使用中文，同时在 metadata 中加入了中文显示名 `日周月报写作助手`。支持读取自定义显示元数据的 Agent 可显示中文名称；只读取标准 `name` 字段的客户端可能仍显示 `work-report-cn`。

## 支持场景

- 写日报
- 写周报
- 写月报
- 写季度总结
- 写阶段复盘
- 写述职材料
- 把多份周报整理成月报
- 把聊天记录 / 待办 / 零散笔记整理成工作总结
- 给“不懂运营/技术的老板”做精简版汇报

## 推荐使用方式

直接把原始记录交给 Agent，例如：

```text
帮我把下面这些零散记录整理成一份本周周报，老板不太懂运营，不要写成流水账，突出结果、进度、问题和下周计划：

……
```

或者：

```text
这是我这个月 4 份周报，帮我整理成月报，不要简单相加，要按业务模块重组，突出累计结果和阶段变化。
```

## 安装方式

### 方式一：通用 Agent Skills 目录

把整个 `work-report-cn` 文件夹复制到：

```bash
~/.agents/skills/work-report-cn
```

跨客户端项目级安装也可以放到：

```bash
<你的项目>/.agents/skills/work-report-cn
```

### 方式二：通过 skills CLI

如果你的 Agent 支持 `npx skills`，可以使用仓库中的技能目录安装：

```bash
npx skills add https://github.com/yannyn3/Publisher-Copy/tree/main/skills/work-report-cn
```

不同 Agent 的安装目录可能不同，以对应客户端的 Skill 文档为准。

## 设计原则

这套 Skill 的核心表达逻辑是：

```text
动作 → 结果 → 当前状态 → 业务价值 / 下一步
```

并在月报中重点强调：

```text
阶段变化 + 累计结果 + 问题 + 下一阶段重点
```

而不是把每周做过的事情重新复制一遍。
