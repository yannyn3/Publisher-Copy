# 日周月报模板

## 日报模板

# 工作日报｜YYYY-MM-DD

## 今日工作

1、完成事项 + 当前结果；

2、推进事项 + 当前状态；

3、其他重要工作。

## 明日计划

1、明日重点事项；

2、明日重点事项；

3、必要的跟进事项。

> 只有确实存在阻塞或需要他人协同时，才增加“问题 / 需协同”模块。

## 周报模板

# 工作周报｜YYYY.MM.DD—YYYY.MM.DD

## 本周工作总结

1、完成 / 推进事项 + 结果；

2、完成 / 推进事项 + 数据；

3、完成 / 推进事项 + 当前状态；

4、培训 / 协作 / 支持事项；

5、平台 / 内容 / 项目进展；

6、其他重要事项。

## 下周工作计划

1、下周重点事项；

2、下周重点事项；

3、下周重点事项；

4、需要继续跟进的工作。

### 周报写法要求

- 默认只保留“本周工作总结”和“下周工作计划”两个主要模块；
- 普通一周总结建议 6—12 条，工作较多可以 10—15 条；
- 每条通常 1—2 句话；
- 有数据直接写数据；
- 同一件事多次推进时合并累计数据；
- 不需要每条都解释业务价值；
- 不自动增加“本周概况、重点成果、问题复盘”等复杂栏目；
- 重要问题可以直接写进对应条目，例如“资料已完成，目前等待审核”；
- 只有用户明确要求时才单独增加“问题与风险 / 需协同事项”。

### 周报示例

# 工作周报｜8.24—8.31

## 本周工作总结

1、完成AI外呼系统学习及交接，并整理销售新人使用教程；

2、跟进GEO上词效果，目前品牌词整体表现稳定，产品词上词难度较高，后续继续调整蒸馏词和场景词；

3、使用视频魔方生成混剪视频20个，一键成片5个，并完成视频拆条等功能测试；

4、发布公众号文章2篇；

5、抖音、快手各发布3个视频，快手新增粉丝15个；

6、与新人一起优化企业知识库，完善GEO写作素材；

7、完成宝盟产品拓词2000+、段落素材30条、断句素材30条、图片素材6张，目前等待相关审核；

8、指导新人学习宝盟基础使用；

9、本周GEO上词1500条，现阶段以品牌词为主，下周开始增加产品词测试；

10、整理企业基础资料，并持续解答销售产品相关问题。

## 下周工作计划

1、调整GEO蒸馏词和场景词，重点测试产品词；

2、推进宝盟审核及正式推广；

3、完善企业知道和电子名片信息；

4、更新公众号及网站内容；

5、制作并测试2—3个优质视频，观察制作时间和播放效果；

6、安排新人继续熟悉T云平台搭建相关产品。

## 月报模板

# 月度工作总结｜YYYY年MM月

## 一、本月整体工作概况

说明本月工作的主线、最重要的结果以及整体推进状态。

## 二、核心业务 / 项目成果

### 1. 项目 A

- 本月目标：
- 累计结果：
- 阶段变化：
- 当前状态：

### 2. 项目 B

同上。

## 三、平台 / 内容 / 系统建设

将相关事项合并为业务模块，突出从0到1、上线、累计产出和当前状态。

## 四、流程建设 / 客户交付

重点写：

- 是否跑通流程；
- 是否形成标准动作；
- 是否形成 SOP / 模板；
- 是否具备独立交付能力；
- 是否提升后续执行效率。

## 五、团队培养 / 内部支持

不要只写“培训了新人”，优先写新人目前已经能独立完成哪些工作。

## 六、本月问题及优化方向

保留2—4个最重要的问题。

每个问题建议写：

**现状 → 原因 / 限制 → 已采取措施 → 下月调整方向**

## 七、下月重点工作计划

保留3—7个真正重要的方向。

## 老板阅读版模板

# 本周工作简报

周报仍建议直接使用：

## 本周工作总结

1、最重要的结果；
2、第二项结果；
3、其他主要进展；

## 下周工作计划

1、重点事项；
2、重点事项；
3、重点事项。

不要因为“老板阅读版”把周报扩展成长报告。

本月主要围绕 **A、B、C** 三个方向推进，目前核心结果如下：

### 1. 核心结果 A

一句话结论 + 关键数据。

### 2. 核心结果 B

一句话结论 + 当前状态。

### 3. 核心结果 C

一句话结论 + 关键进展。

## 当前主要问题

- 问题1：当前影响 + 已采取措施。
- 问题2：当前影响 + 下一步处理。

## 下月重点

1、最重要的目标；
2、第二目标；
3、第三目标。
